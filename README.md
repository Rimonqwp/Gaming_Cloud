
  # Design Cloud Gaming Homepage

  This is a code bundle for Design Cloud Gaming Homepage. The original project is available at https://www.figma.com/design/qJEbkDOKFebMFckAaCL4PP/Design-Cloud-Gaming-Homepage.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Windows 本地启动也可运行 `node scripts/start-local.mjs`。该脚本使用前端端口 3000 和后端端口 8787，复用已运行的服务，等待服务就绪后自动打开 `http://127.0.0.1:3000/dashboard`。新启动的服务会在当前窗口显示日志，按 `Ctrl+C` 停止。
