## 交互与适配

- 搜索“建筑”只显示建筑大赛记录；不存在的名称显示空状态，可清除筛选。
- 手动备份类型筛选显示四项；起止日期筛选显示三个匹配项；下一页显示剩余四项；页面切换、每页数量、时间排序与状态筛选使用真实前端状态。
- 点击名称联动右栏；复选框支持单选、跨页选择、当前页全选与部分选择。单项选中启用还原，多选启用批量删除。
- 创建带名称、描述、7 天保留期的备份后，列表、详情、总数、空间与活动更新。切换概览再返回时记录保留。顶部“备份数据”同样添加记录，不只是显示提示。
- 恢复演示需确认，确认后记入活动。删除需确认，删除后清除选中 ID，选中详情回退到剩余备份。
- 开关切换立即更新已开启/已关闭；设置时间到 05:30、保留天数到 7 后显示新时间。重命名通过行菜单打开表单，保存后更新列表与详情。
- 有效 ZIP 通过本地文件选择器上传，显示原文件名、实际字节数及“浏览器会话”存储位置。伪装为 ZIP 的文本文件显示格式错误；校验扩展名、非空、100 MB 上限与 ZIP 文件头。
- 下载发起浏览器文件下载：上传记录使用原文件，其余记录生成包含 README 和元数据的 `.demo.zip`。浏览器工具的 download 事件等待超时，因此没有确认文件最终落盘；活动和提示使用“已发起”而非宣称下载完成。
- 390 × 844 手机截图 `mobile-final.jpg` 与 1024 × 1100 平板截图 `tablet-final.jpg` 已查看。统计区变为两列、详情下移；手机筛选与操作换行，宽表格在局部容器中横向滚动，根页面无横向溢出。
- 表单、筛选、复选框、开关、菜单、弹窗使用语义控件与可访问名称；活动反馈、错误提示、当前分页与排序状态有对应 ARIA；复用项目焦点与减弱动态效果样式。
