## 交互与响应式验证

已通过浏览器实际操作验证：

- 按扩展名搜索 `.json`、清空搜索、目录导航和空目录状态。
- 新建文本文件、重命名、编辑保存，详情大小随文件内容更新。
- 单选/批量删除、撤销最近删除、文件夹新建。
- 切换玩家管理再回到文件管理后，目录与已创建文件保留。
- 上传真实测试文本文件，列表显示正确的 25 字节大小。
- ZIP 解压生成子目录与文件，编辑器展示 `zip extraction check` 原始内容。
- ZIP 内 `../` 路径被拒绝，并展示明确错误，未写入任何项目。
- 复制路径遭到内置浏览器剪贴板权限限制时，展示完整路径并自动选中，可手动复制。
- 390 × 844 手机、1024 × 900 平板没有页面横向溢出，宽表格在自身容器内滚动。证据为 `mobile-final.jpg`、`tablet-final.jpg`。

下载按钮已触发 Blob 下载并产生相应记录，但内置浏览器没有返回下载完成事件，未验证文件实际落盘。文件夹 ZIP 使用相同的下载机制。当前运行环境的这一限制保留为交付说明。

`npm run build` 通过。浏览器没有新增错误；仅存在项目原有的路由 HydrateFallback 警告。文件操作为内存中的本地演示会话，刷新/退出实例详情会重置，不连接真实服务器文件系统。

ZIP 使用 [fflate 官方接口](https://github.com/101arrowz/fflate/blob/master/docs/functions/unzip.md)，界面图标沿用项目 Lucide 图标库，无需生成位图素材。
